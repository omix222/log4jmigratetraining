Log4j 1.xから2.xへの変換対象キーワード一覧

ExcelマクロでLog4j 1.x設定ファイルや関連ファイルを棚卸しするための検出ルール一覧です。

概要

対象は主に log4j.properties、log4j.xml、派生設定ファイル、依存関係ファイル、Javaソース内のLog4j 1.x API参照です。

Yes はLog4j 2変換後に原則ゼロ件を目指すルール、Review は変換後も残る可能性がある確認対象です。

14. マクロ化する時の判定方針

判定種別使い方
ZeroAfterMigration = YesLog4j 2変換後に原則ゼロ件になるべきルール
ZeroAfterMigration = Review変換後も残る可能性があるため、人手確認対象
Severity = High変換漏れが起動失敗・ログ欠落・二重出力につながる
Severity = Mediumログ形式・運用・監視に影響する
Severity = Low互換性・可読性・性能確認対象

Excelマクロでは、まず ZeroAfterMigration = Yes の件数が0になること を完了条件にし、Review は別シートに出すのがよいです。
